前置条件：用户已登录APP，并进入“用户信息”页面。

输入：

1. 修改昵称时输入新的昵称文本。
2. 更换头像时从本地选择一张图片上传。
3. 点击余额区域获取最新余额。

处理过程：

1. 系统根据当前登录用户手机号码，从数据库查询该用户的头像、昵称、钱包余额，并返回客户端展示。
2. 用户输入新昵称并提交，系统校验昵称是否合法，若合法，将新昵称保存至数据库，保存成功后，客户端实时更新显示新昵称；若校验不通过，弹出提示并保持原昵称不变。
3. 用户从本地选择图片，系统校验图片格式（如jpg、png）和大小，校验通过后，上传图片至服务器或对象存储，并获取图片访问URL，将新头像URL更新至数据库用户信息，保存成功后，客户端实时刷新显示新头像；若校验不通过，弹出提示并保持原头像不变。
4. 用户点击余额按钮，系统重新查询该用户钱包余额，返回最新余额数据，客户端更新显示。

输出：

1. 页面正确展示用户头像、昵称、钱包余额。
2. 昵称修改成功或失败后的提示信息，成功后页面显示新昵称。
3. 头像更换成功或失败后的提示信息，成功后页面显示新头像。
