# 一键导航功能

## 前置条件

1. 用户已点击首页的**“一键导航”**图标。
2. 设备当前处于**联网状态**。
3. 程序已获得**定位权限**。

## 输入

用户通过以下任一方式选择目标充电站：

* 在地图上直接选择充电站；
* 在充电站列表中检索充电站；
* 在充电站列表中直接选择充电站。

## 处理过程

1. **获取当前位置**

   * QT 客户端 → 定位模块：获取当前位置。
   * 定位模块 → QT 客户端：返回当前位置。

2. **获取目标充电站**

   * QT 客户端 → 充电站数据模块：获取目标充电站。
   * 充电站数据模块 → QT 客户端：返回目标充电站经纬度。

3. **请求路线规划**

   * QT 客户端 → 腾讯地图 API：提交起点和终点。
   * 腾讯地图 API → QT 客户端：返回路线规划结果。

4. **加载地图路线规划页面**

   * QT 客户端 → QWebEngineView：加载腾讯地图路线规划页面。
   * QWebEngineView → 腾讯地图 Web 页面：加载并请求路线。
   * 腾讯地图 Web 页面 → QWebEngineView：返回地图页面。

5. **展示导航路线**

   * QWebEngineView → 用户：展示导航路线。

## 输出

跳转至**地图路线规划页面**，并展示从用户当前位置到目标充电站的导航路线。
