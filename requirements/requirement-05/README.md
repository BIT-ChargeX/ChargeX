### 前置条件

1.用户设备已开启定位权限，能够正常获取当前经纬度位置  
2.各充电站的经纬度等地理信息已存储在数据库中，可供查询  
3.设备已联网，能够正常访问腾讯地图Web API  
4.腾讯地图Web API的接入密钥等接入配置已提前申请并配置到客户端中  

### 输入

1.用户在充电站列表中点击的目标电站，用于触发导航流程并确定终点对象  
2.定位模块获取的用户当前位置，作为导航的起点坐标  
3.用户在候选路线列表中选定的具体路线信息，用于发起正式导航请求

### 输出

1.腾讯地图返回的多条候选驾车路线  
2.用户选定其中一条路线后，跳转至嵌入QWebEngineView中的正式路线导航页面
