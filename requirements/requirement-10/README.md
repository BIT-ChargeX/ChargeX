充电订单管理
充电订单生成

- **前置条件**：用户成功选定充电桩，充电桩终端状态正常、可响应上电指令

- **处理过程**：
1. **用户**：在客户端界面确认操作，下发启动充电请求；
2. **客户端**：接收用户操作，组装启动充电请求报文，携带用户 ID、充电桩 ID、充电站 ID，将请求发送至后端业务处理板块；本地提示 “开始充电”；
3. **业务处理板块**：校验用户身份权限、校验充电桩业务状态；校验通过后，向**数据库**发起请求，创建空白充电订单记录；订单状态置为【充电中】，写入用户 ID、充电桩 ID、充电站 ID、充电开始时间；结束时间、充电时长、充电电量、总费用字段留空；
4. **业务处理板块 → TCP 通信板块**：下发上电控制指令；TCP 通信板块透传指令至**充电桩终端**；
5. **充电桩终端**：执行上电，开始充电；持续采集实时充电电量数据，通过 TCP 通信板块回传给业务处理板块；
6. **用户触发停止 / 充满停机 / 故障停机**，充电桩终端产生充电终止事件，经由 TCP 通信板块上报至业务处理板块，上报数据包含：充电结束时间、累计充电电量；
7. **业务处理板块**：接收充电终止上报数据，计算实际充电时长；查询数据库获取该充电站生效计费单价；根据充电电量与计费单价计算充电总费用；
8. **业务处理板块 → 数据库**：回填充电结束时间、充电时长、充电电量、总费用；更新订单状态为【待结算】；执行数据库事务，保证订单数据原子化落库；数据完整性校验，异常则记录日志。
9. **业务处理板块 → 客户端**：回传充电订单结果数据。

- **输出**：客户端展示 “开始充电” 提示；数据库生成状态为【待结算】的完整可结算充电订单。
