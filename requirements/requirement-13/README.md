### 前置条件

1.充电桩基础信息（编号、所属电站、类型、功率等静态属性）已完成录入并存储于系统数据库中  
2.充电桩终端具备状态上报能力，并且与后台服务之间保持正常的网络连接
3.管理员已登录PC服务器端后台管理系统，并拥有充电桩管理及远程操作的相应权限。  

### 输入

1.可选的筛选/分页参数，如按所属电站、类型、状态筛选，或翻页参数；  
2.管理员选中目标充电桩后点击"远程重启"按钮所触发的远程重启操作请求。

### 输出

1.充电桩信息列表表格，展示电桩编号、所属电站、类型（快充/慢充）、功率(kW)、当前状态、累计充电次数、累计充电时长七项字段    
2.远程重启结果提示，在管理员执行远程重启操作后，向其反馈"重启指令已下发/执行成功/执行失败"等结果信息  
3.操作日志记录，记录本次远程重启的操作人、操作时间、目标设备及执行结果
