#前置条件

1.充电桩已完成设备注册与网络接入，与后台服务保持正常的通信连接  
2.充电桩终端具备状态上报能力，能够将自身运行状态（在用、闲置、故障）实时上报至后台系统  
3.管理员已登录PC服务器端后台管理系统，并拥有查看充电桩监控页面的权限  

#输入

充电桩的基础信息（如设备编号，所属站点等标识数据）；  
充电桩终端上报的实时状态数据（在用、闲置，故障）；  
管理员选择的统计维度参数（按站点或者时间段进行筛选）


#输出

系统最终输出一张状态分布统计表格，表格中包含"在用、闲置、故障"三类状态各自的数量以及对应的占比百分比（各状态数量除以总数再乘以100%），并附带充电桩总数的合计行，便于管理员一眼掌握整体规模。通过数量和占比的直观呈现，管理员能够快速判断当前设备的整体运行健康度，例如故障占比过高时可以及时发现异常并介入处理；如有需要，还可以在故障占比超过一定阈值时增加颜色警示等可视化提示，进一步增强预警效果。
