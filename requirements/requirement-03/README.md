 前置条件

1. 用户已进入充电用户端。
2. Qt客户端界面运行正常。
3. 充电站查询功能已经完成，并获得待展示的充电站信息。
4. 业务处理模块运行正常。
5. TCP通信模块运行正常。
6. 数据库连接正常。
7. 数据库中已存在充电站相关基础信息。

 输入

1. 用户进入充电站信息展示页面的请求。
2. 充电站查询结果。
3. 充电站ID。
4. 数据库中的充电站基础信息，包括：
   - 充电站ID
   - 充电站名称
   - 详细地址
   - 经纬度
   - 充电价格
   - 充电桩总数量
   - 当前空闲充电桩数量
5. 用户当前位置与充电站之间的距离信息。

 输出

1. 充电站信息展示列表。
2. 充电站卡片中的核心信息，包括：
   - 充电站名称
   - 充电价格
   - 充电桩总数量
   - 当前空闲充电桩数量
   - 用户当前位置与充电站之间的距离
3. 用户选择指定充电站后对应的充电站ID。
4. 数据获取失败时返回对应的错误状态或错误信息。
