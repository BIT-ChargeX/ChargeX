前置条件
1. 用户已进入充电用户端。
2. Qt客户端界面运行正常。
3. 业务处理板块运行正常。
4. TCP通信板块运行正常。
5. 数据库连接正常。
6. 数据库中已存在充电站相关基础信息。
7. 系统已经获得需要展示的充电站信息。

输出
1. 用户选择的区域信息或手动输入的地址信息。
2. 用户提交的附近充电站查询请求。

处理过程
1. 用户进入充电站信息展示页面。
2. Qt客户端界面向业务处理板块请求充电站信息。
3. 业务处理板块通过TCP通信板块发送充电站信息查询请求。
4. 数据库根据请求查询充电站基础信息。
5. 数据库将查询结果返回TCP通信板块。
6. TCP通信板块将充电站信息返回业务处理板块。
7. 业务处理板块对查询到的充电站信息进行整理。
8. 业务处理板块将整理后的充电站信息返回Qt客户端界面。
9. Qt客户端界面将每个充电站的核心信息以卡片形式进行展示。
10. 用户查看充电站名称、充电价格、充电桩数量、空闲数量以及距离等信息。
11. 用户选择指定充电站后，Qt客户端界面获取该充电站ID，为后续充电桩详情查询提供条件。

输出
1. 用户当前位置对应的经纬度信息。
2. 按照距离由近到远排序的附近充电站列表。
3. 每个充电站的充电站名称、充电价格、充电桩总数量、当前空闲数量以及距离用户当前位置的公里数。
