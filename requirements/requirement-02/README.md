前置条件
1. 用户已进入充电用户端。
2. Qt客户端界面运行正常，附近充电站查询页面可以正常使用。
3. 业务处理板块运行正常。
4. TCP通信板块运行正常。
5. 数据库连接正常。
6. 数据库中已存在充电站相关基础信息，包括充电站名称、地址、经纬度、充电价格、充电桩总数量和当前空闲数量。
7. 腾讯地图 Web API 配置正常，可以完成地址到经纬度的转换。
8. 用户可以通过区域选择或手动输入地址确定当前位置信息。

输入
1. 用户选择的区域信息。
2. 用户手动输入的地址信息。
3. 用户提交的附近充电站查询请求。
4. 用户当前位置对应的经纬度信息。

处理过程
1. 用户进入附近充电站查询页面。
2. Qt客户端界面向用户提供区域选择和地址输入功能。
3. 用户选择区域或手动输入当前位置。
4. Qt客户端界面将用户输入的位置查询请求发送至业务处理板块。
5. 业务处理板块调用腾讯地图 Web API，将用户输入的地址转换为经纬度。
6. 业务处理板块通过TCP通信板块向数据库发送充电站信息查询请求。
7. 数据库根据查询请求返回充电站基础信息及对应经纬度。
8. 业务处理板块根据用户当前位置和各充电站经纬度计算距离。
9. 业务处理板块按照距离由近到远对充电站进行排序。
10. 业务处理板块将排序后的充电站信息返回Qt客户端界面。
11. Qt客户端界面将查询结果展示给用户。

输出
1. 用户当前位置对应的经纬度信息。
2. 按照距离由近到远排序后的附近充电站列表。
3. 每个充电站的以下信息：
   - 充电站名称
   - 充电价格
   - 充电桩总数量
   - 当前空闲充电桩数量
   - 充电站与用户当前位置之间的距离
4. 查询失败时返回对应的错误状态或错误信息。
