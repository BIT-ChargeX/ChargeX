# 附近充电站查询

## 1. 功能概述

附近充电站查询是充电用户端的基础功能。

用户进入充电站查询页面后，可以通过下拉列表选择区域，也可以手动输入地址确定当前位置。系统根据用户输入的位置信息获取经纬度，并查询数据库中的充电站信息，计算用户当前位置与各充电站之间的距离，最终按照距离由近到远进行排序并展示。

该功能用于帮助用户快速查找附近可用的充电资源。

---

## 2. 前置条件

1. 用户已进入充电用户端。
2. Qt 客户端正常启动并可以正常显示充电站查询页面。
3. 数据库连接正常。
4. 数据库中已经存在充电站基础信息，包括：
   - 充电站 ID
   - 充电站名称
   - 详细地址
   - 经纬度
   - 充电价格
   - 充电桩总数量
   - 当前空闲充电桩数量
5. 网络通信模块正常运行。
6. 腾讯地图 Web API 配置正常，可以完成地址与经纬度之间的转换。
7. 用户能够通过区域选择或地址输入提供当前位置。

---

## 3. 输入

### 3.1 区域选择

用户通过 Qt 客户端的下拉框选择所在区域。

###3.2 手动输入地址

用户在地址输入框中输入当前位置。

###3.3 查询请求

系统根据用户选择的区域或输入的地址生成查询请求，并发送至业务处理模块。

---

##4. 输出

系统返回按照距离由近到远排列的充电站列表。

每个充电站至少包含以下信息：

字段	说明
充电站 ID	充电站唯一标识
充电站名称	充电站名称
充电价格	单位：元/度
充电桩总数	当前充电站全部充电桩数量
空闲数量	当前可使用充电桩数量
距离	充电站距离用户当前位置的距离，单位：公里
